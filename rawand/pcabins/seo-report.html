Executive Summary
What We Found

PCabins Factory (مصنع المنزل المحمول) operates a custom-built website at pcabins.com serving the prefabricated cabins, portable rooms, and steel structures market in Saudi Arabia. The site has a professional Arabic-first structure, ISO certifications (9001/14001/45001), references to major clients like Aramco and Riyadh Airports, and active social media presence. However, severe SEO deficiencies mean none of this trust-building content is discoverable by Google.

The most damaging issues are: complete absence of English-language SEO content (missing all B2B procurement searches), no hreflang or canonical tags causing EN/AR duplicate content penalties, no Google Business Profile optimization (missing from local Maps results), and zero content marketing — no blog, no project case studies, no keyword-targeted landing pages. The site is invisible to the corporate clients it serves.

C-01
No English-Language SEO Content — Invisible to B2B Corporate Search
Finding
The entire website is Arabic-first with no English meta titles, H1 headings, product descriptions, or landing pages. Searches like "prefab cabins Saudi Arabia", "portable offices Riyadh KSA", "modular buildings supplier Riyadh", "cabin manufacturer Saudi Arabia" return zero results for pcabins.com. These English queries are used by procurement officers at Aramco, airport authorities, and construction firms — PCabins' highest-value client segment.
Impact
Estimated 60–70% of high-value B2B leads arrive via English search. Corporate procurement portals, expat facility managers, and international construction firms all search in English. Missing this traffic means losing contracts worth SAR 500,000–5,000,000+.
Fix
Create a full English version of the site with keyword-optimized page titles, H1s, and meta descriptions. At minimum: Homepage EN title = "PCabins — Prefab Cabins & Portable Rooms Manufacturer | Riyadh, Saudi Arabia". Add English product category pages targeting: "portable offices", "prefab cabins", "modular buildings", "steel structures Riyadh".
C-02
Zero Hreflang Tags — Arabic & English Pages Treated as Duplicate Content
Finding
The site has both Arabic and English URL structures (via the /en/ switch visible in navigation), but zero <link rel="alternate" hreflang=""> tags exist anywhere on the site. Google cannot determine which version to serve Arabic vs. English users, resulting in both versions competing against each other and being suppressed in rankings.
Impact
Both AR and EN versions receive a duplicate content penalty. Neither ranks well. Google will randomly choose which version to index, often choosing the wrong one for the target audience.
Fix
Good news: The site uses Polylang which automatically generates hreflang tags when configured correctly. Go to Polylang → Settings → URL Modifications and ensure the language switcher is set to "Language URL" mode. Then fix the English URL slugs (see H-09) so the hreflang references correct English URLs. No manual code needed — Polylang handles the output: <link rel="alternate" hreflang="ar-SA" href="https://pcabins.com/"/> <link rel="alternate" hreflang="en" href="https://pcabins.com/en/"/> <link rel="alternate" hreflang="x-default" href="https://pcabins.com/"/>
C-03
No Google Business Profile Optimization — Missing from Local Map Searches

Phone number +966 54 745 3225 is buried in a contact page result — not surfaced by Google as business contact data. Instagram @pcabinsfactory (490+ followers) appears in results but no GMB.

Local search is the #1 source of inbound B2B leads for manufacturers. Competitors appearing in the 3-pack get 44% of all local search clicks. Missing this means losing direct quote requests from nearby corporate clients. Competitor "Beit Al-Majd" has 62 Google reviews and 4.8★ — visible in every local search.

1. Claim/verify Google Business Profile at business.google.com. 2. Set primary name to "PCabins Factory — مصنع المنزل المحمول". 3. Complete all fields: address (7424 Al-Malaz, Adam Bin Rabea Street, Riyadh), phone (+966 54 745 3225), website (pcabins.com), hours. 4. Upload 20+ real factory and project photos. 5. Add categories: "Prefabricated Building Manufacturer", "Modular Building Supplier". 6. Link all social profiles: instagram.com/pcabinsfactory · snapchat.com/@pcabinsfactory · tiktok.com/@portale.house.factory · facebook.com/profile.php?id=61568849312947. 7. Request Google reviews from 5 existing clients immediately.

9 Issues
H-01
No Canonical Tags on Any Page — Duplicate Content Risk
Impact
URL parameter variants (e.g., pcabins.com/?lang=en) create duplicate pages that dilute link equity and cause ranking suppression.
Fix
Add <link rel="canonical" href="https://pcabins.com/[page]"> to every page's <head>. Ensure canonical always points to the primary language version.
H-02
Missing or Generic Meta Descriptions on All Key Pages
Impact
Google auto-generates unflattering meta descriptions from page text. CTR in SERPs drops 20–35% without compelling, keyword-rich meta descriptions.
Fix
Write unique 140–160 character meta descriptions for every page. Homepage example: "PCabins manufactures ISO-certified portable cabins, prefab rooms & modular buildings in Riyadh. 20+ years experience. Serving Aramco, airports & corporations across Saudi Arabia."
H-03
No Schema Markup — Missing Rich Results for Products & Local Business
Impact
Competitors with schema markup get star ratings, pricing, and location in search results. PCabins gets plain blue links. Rich results receive 20–30% higher CTR.
Fix
RankMath SEO is already installed — use its built-in Schema Generator (no coding needed). Enable: (1) LocalBusiness on homepage — add address, phone, ISO certifications in RankMath → Titles & Meta → Local SEO. (2) Product schema on each product page via RankMath → Schema tab. (3) Organization schema with social profiles in RankMath → General Settings → Knowledge Graph. (4) BreadcrumbList — enable in RankMath → General Settings → Breadcrumbs.
H-04
Product Images Have No Alt Text — Google Images Traffic Untapped
Finding
Real product photos are present on all product pages, which is a strong foundation. However, none of the images have descriptive keyword-rich alt text. Google cannot "read" images — alt text is how product photos rank in Google Image Search and contribute to product page SEO authority.
Impact
Google Images is a significant traffic source for visual products like prefab cabins. Product photos with alt text can drive 15–25% additional organic traffic. Missing alt text also fails accessibility audits.
Fix
Add descriptive alt text to every product image: alt="Portable worker housing cabin Riyadh Saudi Arabia", alt="ISO certified steel structure prefab building KSA". Compress images to WebP format to also address the 19.9s mobile LCP. Create a dedicated project gallery page with 16+ project photos.
H-05
No Blog or Content Hub — Zero Topical Authority
Impact
No content = no long-tail keyword rankings. Competitors with blogs about "portable room prices Saudi Arabia", "ISO certified cabins", "prefab office advantages" dominate informational searches that generate B2B inquiries.
Fix
Launch a bilingual blog. Initial articles: (1) "How to Choose ISO-Certified Prefab Cabins for Worker Housing" (2) "Portable Office Cabins vs. Traditional Construction: Cost Comparison" (3) "PCabins Projects: Riyadh Airport Worker Housing Case Study" (4) "كيف تختار كبينة جاهزة مناسبة لمشروعك؟". Target 2 articles/month.
H-06
H1/H2 Heading Structure Weak on Product Pages
Impact
Product/service pages lack keyword-targeted H1 tags in both languages. Google uses H1 as a primary relevance signal. Missing keyword in H1 suppresses rankings for target terms.
Fix
Each product page needs one H1 containing the primary keyword. Example: "غرف متنقلة جاهزة | Portable Ready Rooms". Follow with H2 subheadings covering specs, uses, pricing factors, and ISO compliance.
H-07
No Review or Testimonial Strategy — Zero Social Proof in SERPs
Impact
Google Business Profile with 0 reviews vs. competitors with 50+ reviews. B2B buyers check reviews before requesting quotes. No reviews = no credibility = lost leads. Review schema triggers star ratings in search results.
Fix
1. Request Google reviews from 5 existing satisfied clients immediately. 2. Add testimonials from Aramco and airport projects to website with schema markup. 3. Create a case study page: "Our Work with Riyadh Airports Company". 4. Add Review schema to the testimonials page.
H-08
Sitemap Not Submitted to Google Search Console
Impact
Pages may not be crawled and indexed promptly. New pages can take weeks to appear in Google without active sitemap submission.
Fix
1. Set up Google Search Console for pcabins.com (verify via DNS or HTML file). 2. Submit sitemap at https://pcabins.com/sitemap.xml. 3. Request indexing for all key pages. 4. Monitor for crawl errors weekly.
H-09
Arabic URL Slugs Used on English Pages — Invisible to English Search
Finding
The English version of the Services page has the URL: pcabins.com/en/%d8%a7%d9%84%d8%ae%d8%af%d9%85%d8%a7%d8%aa-en/ — the encoded string %d8%a7%d9%84%d8%ae%d8%af%d9%85%d8%a7%d8%aa is the Arabic word الخدمات (services). The same pattern likely applies to all English pages: products, projects, and contact. English-speaking users and Google both see URL-encoded Arabic characters instead of readable English words.
Impact
URL slugs are a ranking signal. /en/services/ reinforces keyword relevance for "services" searches; /en/%d8%a7%d9%84%d8%ae%d8%af%d9%85%d8%a7%d8%aa-en/ contributes nothing. It also looks broken and untrustworthy when shared in emails or WhatsApp — reducing click-through rate.
Fix
The site runs on WordPress + Polylang. In Polylang settings, each page has a separate slug per language — set the English slug explicitly to readable English words: /en/services/, /en/products/, /en/projects/, /en/contact/. The Arabic version keeps Arabic slugs (/الخدمات/). Polylang automatically generates the hreflang tags once both slugs are set correctly. This is a one-time fix with lasting SEO benefit.

Fix

Mobile LCP 19.9s — Catastrophic Load Time Despite 65/100 Score
Fix
Convert all product images to WebP format (avg 80% size reduction). Fix render-blocking resources identified in PageSpeed Insights. Configure WP Rocket properly — enable lazy load, minify CSS/JS, and enable LiteSpeed Cache integration. Add Cloudflare CDN (free tier). Target: LCP under 3s, mobile score 75+/100.

No Internal Linking Strategy Between Product Pages
Fix
Add contextual internal links between related products. Example: "Portable Cabins" page should link to "Steel Structures" and "Worker Housing". This distributes PageRank and helps Google understand site structure.
