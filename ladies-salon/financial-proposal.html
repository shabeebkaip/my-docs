Executive Summary
ملخص تنفيذي
CodeOx Technologies is pleased to present this comprehensive Financial Proposal for the implementation of Odoo 19 Enterprise at Andel Hands Beauty Centre. The proposed solution will transform the salon's current manual, paper-based operations into a fully integrated digital platform — enabling data-driven management, automated commissions, customer loyalty, and targeted WhatsApp marketing campaigns.

The solution is hosted on a dedicated Premium server at LightNode's Riyadh data center, ensuring compliance with Saudi data residency requirements and delivering optimal performance for the local user base.

Project Objectives
أهداف المشروع
01
Digitize Daily Operations
Replace paper-based records with a fully integrated POS that captures every transaction, issues e-invoices, and manages daily workflows with precision.
02
Build a Customer Database
Create comprehensive customer profiles including visit history, services, and spending — with a loyalty program active from Day 1.
03
Control Commissions & Discounts
Automate tiered staff commission calculations and enforce cashier discount limits with an approval workflow for exceptions.
04
WhatsApp Marketing Automation
Launch targeted outbound marketing campaigns via WhatsApp Business API — birthday offers, appointment reminders, digital receipts.
05
ZATCA Phase 2 Compliance
Implement e-invoicing as required by ZATCA Phase 2, with 15% VAT applied automatically at point of sale.
06
Secure Local Cloud Hosting
Run the system on a dedicated Premium VPS in Riyadh (LightNode) for maximum performance, security, and local data compliance.

Scope of Work
نطاق العمل
Phase 1
Discovery & Requirement Analysis
In-depth review of current operations to identify gaps and design the optimal solution architecture.
  • Business process review session with management
  • Gap analysis and requirements documentation
  • Solution architecture and module mapping
  • Service catalogue data collection (Arabic/English, prices, durations)
Phase 2
Odoo Configuration & Setup
Installation and configuration of all required Odoo modules tailored to the salon's workflow.
  • Company setup and master data configuration
  • Salon-flavored POS setup
  • Accounting module with Saudi chart of accounts
  • CRM and customer master configuration
  • User roles and permission setup (Cashier, Manager, Accountant, Admin)
  • Loyalty program mechanics and rules configuration
  • Custom tiered commission engine setup
  • ZATCA e-invoicing module configuration
Phase 3
Data Migration
Import and validate all master data before go-live.
  • Service catalogue import (items, prices, duration)
  • Staff onboarding and commission structure setup
  • Data validation and sign-off
Phase 4
WhatsApp Business API Integration
Full integration of WhatsApp Business API for digital receipts and outbound marketing.
  • WhatsApp Business API account setup and verification
  • Meta-approved message template design
  • Odoo integration for automated receipts and reminders
  • Marketing campaign scenario setup (welcome, birthday, re-engagement)
Phase 5
User Training
Comprehensive hands-on training for all user roles before go-live.
  • Administrator and accountant training (accounting, VAT, reports)
  • Cashier training (POS, discounts, loyalty)
  • Manager training (commission reports, dashboard, KPIs)
  • Arabic user manual delivery
Phase 6
UAT & Go-Live
Full system testing, production deployment, and intensive post-launch support.
  • User acceptance testing (UAT) with client sign-off
  • Production environment deployment
  • Hypercare support for the first two weeks of live operation
  • Post-launch review session
