Overview
Executive Summary
Code-ox Technologies is pleased to submit this commercial quotation for a fresh Odoo Enterprise ERP implementation for Alamco Spaceworks — bringing sales, procurement, inventory, projects, HR and finance into one connected system.

Per our last meeting, the agreed direction is to implement the ERP first and build a solid operational foundation, then revisit the AI procurement agent as a natural next phase once the ERP is live and your data lives in one place. This proposal is therefore focused purely on standing up Odoo end-to-end for a 5-user rollout, with the full module set configured around how Alamco actually runs projects.
Phased approach

Phase 1 (this proposal): Full Odoo Enterprise ERP implementation.  Phase 2 (future): The AI Procurement Agent that reads BOQs and raises requisitions — quoted separately once the ERP is live and the catalogue and vendor data are in Odoo.

Scope of Work
The full Odoo module suite
Your Odoo Enterprise subscription unlocks every Odoo application — not a limited bundle. This implementation configures the core operational modules below around Alamco's workflows; any additional app can be switched on at any time at no extra licence cost.
Sales & Customers
  • CRM — leads, tenders & client/consultant pipeline
  • Sales — BOQ-style quotations, revisions, price lists
  • Sign — digital sign-off on quotes & contracts
Procurement & Inventory
  • Purchase — RFQs, vendor price lists, PO-to-bill, approvals
  • Inventory — multi-location stock, per-project reservation
  • Manufacturing — optional, for in-house joinery/BOM
Projects & Delivery
  • Project — every fit-out job as a project, cost vs BOQ
  • Timesheets — labour hours booked to projects
  • Field Service / Planning — site scheduling (optional)
Finance
  • Accounting — full AR/AP, bank reconciliation, reporting
  • Invoicing — ZATCA e-invoicing compliance
  • Expenses — staff expense capture & approval
Human Resources
  • Employees — directory & records
  • Time Off & Attendance — leave and presence
  • Recruitment — hiring pipeline (optional)
Productivity & Platform
  • Documents — central file store, linked to records
  • Discuss & Approvals — internal chat, approval flows
  • Dashboards — live KPIs across every module
Note on module access

Modules marked optional are available on the same licence and can be activated whenever Alamco needs them — the implementation prioritises the operational core (Sales, Purchase, Inventory, Project, Accounting, HR) so you go live quickly, then expands from there.

Odoo.sh price breakdown (Odoo · Saudi Arabia)

1 worker $57.60/mo ($691.20/yr) + 80 GB storage $16.00/mo ($192/yr, at $2.40/GB/yr) + 1 staging branch $14.40/mo ($172.80/yr) = $88.00 / month ($1,056 / year). Storage is sized at 80 GB for this project. Hosting is charged per instance, not per user — the same for 5 users.

Our recommendation

Two solid choices: LightNode — the lowest-cost, low-latency option with Middle-East server locations, set up and maintained by Code-ox; or Odoo.sh — fully managed by Odoo (backups, staging, upgrades) for a hands-off setup. Both run Odoo Enterprise and support the custom code needed for the Phase-2 AI agent.

Hosting fees are paid to Odoo (Odoo.sh) or the VPS provider, billed in USD; SAR indicative at 3.75, confirmed at provisioning. All options run Odoo Enterprise, already covered on the previous page.
