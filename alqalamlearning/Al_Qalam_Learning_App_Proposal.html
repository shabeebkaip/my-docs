01Project Summary

Al Qalam Learning becomes a fully digital school — students view their schedule, homework, attendance, and marks from a single mobile app. Teachers mark attendance, upload materials, and communicate directly with students. Administrators run admissions, calendars, reports, and broadcasts from a dedicated web console. All three roles share a single source of truth, accessible on phone, tablet, and desktop.

Powers: All three apps
One source of truth. Battle-tested Node.js API on a dedicated cloud VPS, with MongoDB powering flexible data storage for students, classes, marks, content and chat history. Real-time delivery via Socket.io.

07Security & Data Protection

Security is built in at every layer — from how passwords are stored to how data is backed up. Six controls, all standard practice for production systems handling student and family data.

🔐
JWT Authentication
Industry-standard token-based auth. Short-lived access tokens, secure refresh flow.
👥
Role-Based Access Control
Student / Teacher / Admin see only what their role allows — enforced at the API.
🔒
bcrypt Password Hashing
Passwords never stored in plain text. One-way hashed with adaptive cost factor.
🛡️
HTTPS Everywhere
TLS 1.3 across all clients & APIs. Auto-renewing Let's Encrypt certificates.
💾
Encrypted Backups
Daily MongoDB snapshots, encrypted at rest, 30-day retention with point-in-time recovery.
📜
Audit Logging
All admin actions logged — who changed what, when. Full accountability trail.
