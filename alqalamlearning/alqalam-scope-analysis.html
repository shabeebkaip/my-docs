01What Al Qalam Asked For

A combined School ERP + LMS + Islamic-education platform delivered as a mobile app (iOS + Android), an admin / teacher web portal, and — per round 2 of discussions — a desktop-accessible student web portal. The original feature list spanned 18 modules covering school operations, learning, Islamic studies, communications, certificates, admissions, and platform extras.

Honest size read This is comparable in scope to Classera / Teachmint / Edmingle + a custom Islamic layer. It is not a small app. Shipped without a phase plan, this becomes a 9–12 month build. With CodeOx's recommended phasing, Phase 1 ships in 3 months with the features the client marked as essential.
02Apps to be Built
📱
Mobile App — iOS + Android
React Native (Expo) · single codebase
Users: Student, Teacher (role-based login)
Day-to-day usage — attendance, homework, fees view, notifications, study materials, certificates, 1:1 chat with teacher.
🖥️
Web Portal — Admin + Teacher
Next.js 16 (App Router) on Vercel
Users: School Admin, Principal, Teachers
Heavy data entry — admissions review, fee setup, exam & marks entry, broadcast announcements, bulk uploads, financial & attendance reports.
💻

Same Next.js codebase · different routes
Users: Students (browser version of the mobile app)
Confirmed in round 2 — "Mobile and desktop il access option venamtto". Students can access notes, homework, calendar, certificates, and chat from any browser on PC, laptop, or tablet.

Backend (shared by all apps)
Supabase · Postgres + Auth + Storage + Realtime
Used by: All three frontends
Single source of truth — user data, content, files, real-time events for chat & notifications. Push delivered via Expo Notifications.

07Open Clarifications — Required Before Final Proposal
Q1 · Parent access in Phase 1? Parent Portal marked ❌ across the board, yet "parent messages" and "fee reminders" are ✅. Who receives them? Options: (a) parents log in via student account, (b) parents notified via WhatsApp / SMS only, (c) misclick — parents do need login. Need decision.
Q2 · Fee reminders without fee details? Reminders ✅ but fee details ❌. Likely the admin enters dues in backend; parents only get push (no amount). Confirm interpretation.
Q3 · No Islamic features in Phase 1? Surprising for an Islamic school — all of Quran / Salah / Adhkar deferred. Likely intentional (ship core school ops first). Confirm with client that they accept launching without these for the first 3 months.
Q4 · Operating region? Determines payment gateway (Razorpay vs HyperPay vs Tap), data residency, and compliance baseline. Confirm country/region.
