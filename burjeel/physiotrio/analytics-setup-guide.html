Level up — all inside GTM, no developer

whenever
you're ready

Because GTM is installed site-wide, everything below is done from tagmanager.google.com → New Tag → Publish. The website never changes again.

💬

WhatsApp click = your #1 conversion

Bookings on this site happen via WhatsApp. In GTM: new Trigger → Just Links → Click URL contains "wa.me" → attach a GA4 Event tag named whatsapp_click. Now you can see exactly which pages create bookings.

📞

Phone-call clicks

Same trick: trigger on Click URL contains "tel:" → GA4 event phone_click. Two triggers = both conversion paths measured.

📣

Ad pixels, when campaigns start

Meta Pixel, TikTok, Snap, Google Ads — each is just another tag in GTM. Add → Publish → live. No code, no tickets, no waiting.

✓

The WhatsApp recipe, step by step

Click
In GTM: Triggers → New → trigger type Just Links
Pick
Some Link Clicks → condition: Click URL → contains → wa.me (if "Click URL" isn't in the dropdown, click Choose Built-In Variable and enable it) → Save as WhatsApp Link Click
Click
Tags → New → tag type Google Analytics: GA4 Event
Type
Measurement ID → your G-XXXXXXXXXX   Event Name → whatsapp_click
Pick
Triggering → your new WhatsApp Link Click trigger → Save
Click
Test in Preview (click a WhatsApp button, watch the tag fire) → Submit → Publish. Yes, again — every GTM change needs Publish
⭐
Mark it as a conversion: after clicks start flowing, go to GA4 → Admin → Data display → Events → flip the "Mark as key event" toggle on whatsapp_click. Note: the event appears in that list up to 24 hours after it first fires — if it's not there the same afternoon, that's normal, check tomorrow.

"Help, it's not working!" — 30-second fixes

0️⃣
GA4 shows zero users: 90% of the time you forgot Submit → Publish in GTM (Part 3). Check that first, always.
🕐
Realtime works but reports are empty: normal — main reports take 24–48 hours to populate. Trust Realtime.
🔁
Pasted the ID but nothing loads: double-check there's no space before/after the ID in the admin field, press Save again, wait 30 seconds, hard-refresh the site (Ctrl/Cmd+Shift+R).
🧱
Tag Assistant won't connect: disable ad-blockers for physiotrio.com, or test in a normal (non-incognito) Chrome window.
