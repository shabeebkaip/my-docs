13Risks & Dependencies

What could slow this down.

Payment APIs
Payment processing is owned by Nixpend — the API contract (methods, tokenization, refunds, webhooks) is not yet confirmed. Must be checked before FR-A6 build begins.
Wearable Integrations
Apple Health, Samsung Health, and WHOOP are confirmed and direct. Mi Health (Xiaomi) has no confirmed public API — do not commit it until verified.
Nixpend Availability
Nixpend HMS is the system of record for availability, bookings, and clinical facts. The app's core loop depends entirely on its uptime and API contract.
Compliance
Health data is Sensitive/Tier-4 under Saudi PDPL. Cloud-based wearable APIs need real legal review for cross-border data transfer before commitment.
