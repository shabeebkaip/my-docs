How to use this book

Tester nameclick to type…
Test cycle / dateclick to type…
Build / branch under testclick to type…
Each module is its own page (links below). On every page set a case Status (Pass / Fail / Blocked / Not Run) and type in Notes. Everything auto-saves to this browser (localStorage) and is shared across all pages, so your tester name and every result persist as you move between sections. Use Print → Save as PDF per page for a signed report.
Results auto-save into the repository. One-time setup: click ⚡ Connect results.json (bottom-right corner of any page) and pick abjad/tests/results.json in this repo. From then on every status and note you enter writes to that file automatically — no save button. The green "✓ Auto-saving" pill confirms it's on; next visits just need one click on ▶ Resume. Connecting also loads whatever results are already in the file, so a new tester or machine continues where the last one stopped. When done for the day, commit & push tests/results.json. (Chrome/Edge required for auto-save; other browsers get a manual download button instead.)
