Edge Cases, Errors & Responsive

Empty states, invalid inputs, upload limits, network failures, and responsive/mobile checks across the platform.

IDPriTest case · steps · expectedStatusNotes
EDGE-01Empty states. Fresh accounts: jobs with no results, no applications, no interviews, no notifications, empty shortlist. Expect: friendly empty states with CTAs, never blank/broken screens.
EDGE-02Invalid form input. Submit forms with empty required fields, wrong types, negative salary, XSS-like strings. Expect: validation blocks; server sanitizes; no crash / no script execution.
EDGE-03File upload limits. Upload oversized files and wrong types (logo >2MB, non-image photo, non-PDF CV). Expect: rejected with a clear message; 2MB logo cap enforced.
EDGE-04Expired OTP path. (Cross-ref AUTH-07.) Use an expired OTP. Expect: clear expiry error + resend path.
EDGE-05Network failure handling. Throttle/kill network during a save or payment. Expect: graceful error/loading state, retry possible, no silent data loss.
EDGE-06404 / invalid IDs. Visit a non-existent job/candidate/plan URL. Expect: clean not-found state, no stack trace.
EDGE-07Long content / overflow. Very long names, cover letters, descriptions. Expect: truncation/wrapping; no layout break in list or cards.
EDGE-08Responsive — mobile. View key pages (jobs, apply modal, dashboard, checkout) at ~375px. Expect: usable, tappable, no horizontal scroll; modals fit.
EDGE-09Responsive — tablet. Repeat at ~768px incl. school candidate table + admin panel. Expect: layouts adapt; tables scroll/stack sensibly.
