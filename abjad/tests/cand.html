Candidate Search

Route /school/candidates. Default sort Best Match (AI). Filters: subject, grade, city, certifications keyword, language + proficiency, availability, max budget (nationality is intentionally deferred). Bulk shortlist + PDF export (capped at 100). Candidate profile modal with Profile / History tabs.

IDPriTest case · steps · expectedStatusNotes
CAND-01Search loads with Best Match default. Open /school/candidates. Expect: approved teachers listed; sort defaults to Best Match (AI ranking), not Newest.
CAND-02Match badge on cards. Inspect candidate cards. Expect: a match % badge is surfaced per candidate.
CAND-03Subject + grade filters. Filter by subject and grade. Expect: results narrow correctly.
CAND-04Certifications keyword filter. Enter a certification keyword. Expect: only candidates with a match.
CAND-05Language + proficiency filter. Filter by language and level. Expect: results respect both.
CAND-06Availability filter. Filter Immediate / Notice. Expect: results respect availability.
CAND-07Max budget filter. Set a max salary expectation. Expect: candidates over budget excluded.
CAND-08Sort options. Switch to Newest / Most experienced. Expect: ordering changes accordingly.
CAND-09Bulk select + shortlist. Select multiple candidates, bulk shortlist. Expect: all added to a shortlist; feedback shown.
CAND-10PDF export cap 100. Select candidates and export PDF; try selecting >100. Expect: PDF generated; export capped at 100 with a clear notice.
CAND-11Profile modal — Profile tab. Open a candidate. Expect: full profile (personal/professional/education/certs/CV) in the Profile tab; actions available (shortlist/reject/invite/notes).
CAND-12Profile modal — History tab. Switch to History. Expect: interaction history scoped to THIS school only (privacy); previous applications/interviews with this school.
