Application Management & Interview Scheduling

Route /school/applications and /school/interviews. Review candidates, move status through the lifecycle, schedule interviews, and record feedback. Status: Submitted → Reviewing → Shortlisted → Interview Scheduled → Offer → Hired / Rejected.

IDPriTest case · steps · expectedStatusNotes
SAPP-01Applications list. Open /school/applications. Expect: applicants per job with status, match score, reference #.
SAPP-02Application review panel. Open an application. Expect: teacher summary, cover-letter preview, match score, ref #.
SAPP-03Shortlist. Move an application to Shortlisted. Expect: status updates; teacher's tracker reflects it.
SAPP-04Reject with reason. Reject an application with a reason. Expect: status → Rejected; reason captured; teacher notified.
SAPP-05Schedule interview. From an application, open ScheduleInterviewModal; set date, type, link, interviewer, duration. Expect: interview created; teacher receives invite.
SAPP-06Interview types. Try each interview type (incl. Abjad-coordinated where present). Expect: type-specific fields behave correctly.
SAPP-07School interviews view. Open /school/interviews. Expect: scheduled interviews listed with status; reschedule available.
SAPP-08Interview feedback form. After an interview, record feedback: rating 1–5, strengths, weaknesses, Hire/Maybe/Reject, notes, evaluator. Expect: saved and shown on the application.
SAPP-09Reschedule reflects to teacher. Reschedule an interview. Expect: teacher sees updated time / reschedule request.
SAPP-10Status lifecycle integrity. Walk one candidate Submitted→Reviewing→Shortlisted→Interview→Offer→Hired. Expect: each transition valid; no skipping backwards illegally; teacher tracker mirrors it.
SAPP-11Bulk reject. Select multiple applications and bulk reject with a shared reason. Expect: all move to Rejected; each teacher notified.
