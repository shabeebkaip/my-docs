Auth & Sessions

Covers teacher/school signup, email-OTP verification, login, password recovery, remember-device, and session behaviour. Routes: /register, /verify-otp, /login, /forgot-password, /reset-password, /choose-role. OTP prints to the backend terminal.

IDPriTest case · steps · expectedStatusNotes
AUTH-01Choose role page. Open /choose-role. Expect: two clear paths (Teacher, School); selecting each routes to the matching registration form.
AUTH-02Teacher signup — happy path. On /register enter name, email, password, mobile; submit. Expect: account created, redirected to /verify-otp, OTP printed in backend terminal.
AUTH-03Signup validation. Submit with blank/invalid email, weak password, malformed mobile. Expect: inline field errors; no account created; submit blocked.
AUTH-04Duplicate email. Register with an email that already exists. Expect: clear "already registered" error, no duplicate created.
AUTH-05Email OTP verification. On /verify-otp enter the code from the backend terminal. Expect: account verified, redirected into the app (teacher dashboard / profile). Confirm delivery is EMAIL not SMS — expected behaviour.
AUTH-06Wrong OTP. Enter an incorrect 6-digit code. Expect: error shown, not verified, can retry.
AUTH-07Expired OTP. Wait past the code's validity window, then submit the old code. Expect: "expired" error; a fresh code must be requested.
AUTH-08Resend OTP + 60s cooldown. Click Resend. Expect: new code sent; Resend disabled with a 60s client countdown (no backend throttle — expected).
AUTH-09Login — valid. On /login enter verified credentials. Expect: teacher lands on /dashboard, school on /school/dashboard; session cookie set.
AUTH-10Login — wrong password. Enter a valid email with wrong password. Expect: generic "invalid credentials" error (no user-enumeration leak).
AUTH-11Remember this device — checked. Login with the box ticked, close browser, reopen. Expect: still logged in; session persists ~30 days.
AUTH-12Remember this device — unchecked. Login unticked; close all windows / end session. Expect: session-cookie only, expires within ~1 day; reopening a new session requires login.
AUTH-13Password recovery. /forgot-password → enter email → follow reset link/token → set new password on /reset-password → login with it. Expect: reset succeeds, old password rejected.
AUTH-14Logout. From any authed page, log out. Expect: session cleared, redirected to login; back button does not restore an authed page.
