School Registration & Verification

Route /school/profile. Fields incl. curriculum, CR number, license number, head of school, default salary/daily rate. Verification is scoped to 2 documents (Commercial Registration + License) — tax cert & authorization letter are intentionally skipped.

IDPriTest case · steps · expectedStatusNotes
SCH-01School signup. Register a school account via choose-role → school. Expect: account created; email OTP verification as with teachers.
SCH-02School info fields. Fill name, curriculum, city, head of school, CR number, license number. Expect: saved; enum values (curriculum/type) accepted.
SCH-03Default salary / daily rate. Set defaults used to prefill job posts. Expect: persisted; SAR displayed.
SCH-04Logo upload (2MB cap). Upload a logo. Expect: image types only; files >2MB rejected with a clear message; preview updates.
SCH-05Upload CR document. Upload Commercial Registration. Expect: stored, filename shown, viewable.
SCH-06Upload License document. Upload License. Expect: stored/viewable. Confirm only these 2 docs are required — no tax cert / authorization letter fields (expected).
SCH-07Submit for verification. Submit school for review. Expect: status → Pending; appears in admin queue.
SCH-08Verified / rejected reflects. After admin verifies (or rejects w/ reason), reload. Expect: Verified badge (or rejection + reason); verified schools can fully post/hire.
SCH-09Edit profile revalidation. Edit a key field post-verification. Expect: change logged; re-verification triggered where applicable.
