Job Posting

Route /school/jobs. Bilingual title (Ar+En) with auto-suggest, structured description (Responsibilities/Requirements/School culture/Benefits × Ar/En with 2000-word counter — plain textareas by design, NOT rich text), certifications, schedule + contract-duration mode, daily rate, campus, salary display modes, Preview step, and Active/Draft/Closed/Expired management tabs.

IDPriTest case · steps · expectedStatusNotes
SJOB-01Open create form. On /school/jobs click New Job. Expect: multi-field modal/form opens.
SJOB-02Bilingual title + auto-suggest. Enter subject; observe title suggestion; fill Ar + En titles. Expect: auto-suggested title based on subject; both languages saved.
SJOB-03Structured description × Ar/En. Fill Responsibilities / Requirements / School culture / Benefits in both languages. Expect: plain textareas (by design), 2000-word counter enforced.
SJOB-04Subject / grade / contract type. Set subject, grade levels, contract type. Expect: saved; valid enum values.
SJOB-05Contract-duration mode. Choose By Day / By Month / By Year. Expect: mode toggles the relevant rate fields.
SJOB-06Daily rate for substitute. Set contract type substitute + daily rate. Expect: daily-rate field present and saved.
SJOB-07Campus field. For a multi-campus school, select campus. Expect: field shown when applicable, saved.
SJOB-08Certifications. Add required + preferred certifications. Expect: both lists saved and shown on the posting.
SJOB-09Salary display mode. Pick Show / Negotiable / Hidden. Expect: teacher-facing card respects the chosen mode.
SJOB-10Start date + deadline. Set start date and application deadline. Expect: both saved; deadline drives expiry.
SJOB-11Preview step. Click Preview before publishing. Expect: a preview of the posting shown; can go back to edit; publish is a separate confirm.
SJOB-12Publish. Confirm publish. Expect: job goes live, appears under Active and in teacher /jobs search.
SJOB-13Management tabs. Check Active / Draft / Closed / Expired tabs; save a draft; close a job. Expect: jobs land in the correct tab; expired jobs auto-move past deadline.
