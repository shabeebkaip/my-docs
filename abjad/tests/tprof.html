Teacher Profile

Route /profile. Sections: personal, professional, education, certifications, CV, languages, location, salary, employment status. Approval lifecycle: Draft → Pending → Approved / Rejected / Suspended. Major edits re-trigger approval.

IDPriTest case · steps · expectedStatusNotes
TPROF-01Personal info. Fill name, DOB, gender, nationality, contact; save. Expect: persists after reload; RTL-correct in Arabic.
TPROF-02Professional info + employment status. Set subjects, grade levels, years of experience, and one of the 3 employment statuses; when "employed/serving notice" set notice period (0–180 days). Expect: conditional notice field shows/hides correctly; backend sanitizes out-of-range values.
TPROF-03Education & credentials. Add degree(s), institution, year. Expect: multiple entries supported, save/edit/delete work.
TPROF-04Certifications. Add certifications with issuer/date and file. Expect: entries listed; uploaded file viewable.
TPROF-05CV upload. Upload a PDF CV. Expect: upload succeeds (Cloudinary), filename shown, downloadable; oversized/invalid type rejected with a clear message.
TPROF-06Photo upload. Upload a profile photo. Expect: preview updates; only image types accepted; size limit enforced.
TPROF-07Languages, location & salary preference. Set languages + proficiency, preferred cities, expected salary (SAR). Expect: saved; currency shown in SAR.
TPROF-08Submit for approval (Draft→Pending). Complete required fields and submit. Expect: status flips Draft→Pending; profile becomes read-only-ish / shows "under review".
TPROF-09Approved / Rejected reflect from admin. After admin approves (or rejects with reason), reload profile. Expect: teacher sees Approved badge (or Rejected + reason); Approved profile becomes searchable by schools.
TPROF-10Change-triggered re-approval. On an Approved profile edit a major field (e.g. subjects). Expect: status auto-flips back to Pending; a field-level change entry is logged (visible to admin via History).
TPROF-11Suspended state. With profile suspended by admin, log in as teacher. Expect: suspended banner; restricted actions; profile hidden from school search.
