# Vitality Mobile App — Pitch Deck Image Prompts

Fact-checked against all 10 source docs — see `00-master-brief.md` for the full reference these prompts are drawn from.

Copy each slide's prompt into ChatGPT image generation one at a time (each is self-contained, so order doesn't matter). Save the output as `vitality/assets/deck/0X-name.png` to match the `<img>` paths wired up in `vitality/mobile-app/pitch-deck.html`.

Slide 1 (cover) is already done — `vitality/assets/deck/01-cover.png`. Use it as the visual anchor for consistency.

**Shared style system (repeated in every prompt so each generation is self-contained):**
- Colors — Navy `#001229` (darkest bg), `#001C3D` (primary/trust surfaces), `#002B5B` (elevated). Gold `#C5A059` (primary — progress/CTA/achievement only, never decorative), `#D4B67C` (secondary), `#F9F3E8` (wash). Ivory `#FDFCFA`/`#F7F5F0` (page/card bg, ~80% of the palette). Accents used only for status: sage `#8FAE8B` (calm/recovery), sky `#7FA8C4` (info), blush `#D9A08F` (gentle), apricot `#E0A85E` (attention). No red anywhere.
- Type — elegant thin-weight serif display for headlines (stand-in for Termina), clean geometric sans-serif for body/labels (stand-in for Montserrat), authentic Arabic script for Arabic lines (stand-in for Noto Sans Arabic).
- Logo lockup, top-left of every slide: small gold "V" chevron mark + "VITALITY" (bold navy or gold caps) + "HOME HEALTH SERVICES" + "BY BURJEEL ARABIA" (small caps, subdued).
- Mood: "quiet luxury, domesticated" — a private suite, not a hospital or a government portal. Warm, editorial photography quality, soft depth of field, generous rounded corners (20-28px), warm navy/gold-tinted shadows (never grey/flat).
