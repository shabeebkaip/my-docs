Section 3
Vendor Profiles
PRTG Network Monitor
Paessler AG · paessler.com/prtg
⭐ Tier 1 — Recommended

Founded 1997; 500,000+ installations globally. Widest sensor library (200+ types). Consistently ranked as the most user-friendly SolarWinds NPM replacement with fastest migration path.

Licensing
Per-sensor perpetual. XL (unlimited) license recommended for this scale. Typical 5,000-sensor: USD 15–25K one-time + 25% annual maintenance.
Server OS
Windows Server (primary). Linux via remote probes only. HA via Windows failover cluster.
Flow Support
NetFlow v5/v9, sFlow, IPFIX — included in base product via flow sensor.
ServiceNow
Via webhook/REST — no native certified connector. Requires configuration.
Strengths
  • Most intuitive UI — lowest learning curve from SolarWinds
  • 200+ out-of-box sensor types cover almost any device
  • Fastest time-to-value post-migration
  • Strong community and documentation
  • XL license eliminates per-sensor cost management
Weaknesses
  • Windows Server required — no full Linux server support
  • No native ServiceNow connector
  • Sensor-based licensing gets complex at scale if not on XL
  • Flow analysis less feature-rich vs. dedicated NTA tools

WhatsUp Gold
Progress Software · whatsupgold.com
⭐ Tier 1 — Alternative

30+ year track record as a direct SolarWinds NPM competitor. Acquired by Progress Software in 2010. Strong US/UK enterprise install base. Growing in Middle East.

Licensing
Annual subscription per device. WhatsUp Gold Total Plus (all modules): ~USD 8–20K/year. 14-day free trial.
Server OS
Windows Server only — no native Linux deployment. MS SQL required (not bundled). Key constraint.
Flow Support
NetFlow, sFlow, IPFIX built into base product. Good top-talker and application views.
ServiceNow
Via REST webhook — no native certified connector. Configurable but requires setup.
Strengths
  • Clean, modern UI with strong dashboards
  • Long track record as SolarWinds NPM direct alternative
  • Flow analysis, topology, and alerting all in base product
  • Dependency-aware alert suppression built in
Weaknesses
  • Windows Server only — significant if Linux preferred
  • Limited GCC/KSA regional presence — EMEA support routed
  • Smaller ecosystem vs. PRTG; limited GCC regional presence
  • No healthcare-specific GCC references readily available
CodeOx Assessment — WhatsUp Gold

Solid platform but the Windows-only constraint and limited KSA support are concerns. Solid alternative if PRTG cannot meet commercial requirements. Recommended as Tier 2 fallback.

Zabbix Enterprise
Zabbix LLC · zabbix.com  ·  Open Source (GPL) + Commercial Support
✅ Tier 2 — Budget Path

Open source enterprise monitoring founded 2001. Core software is free (GPL); Zabbix LLC sells commercial support and professional services. Proven at 100K+ node deployments globally. Native HA since v6.0 (2022). Best-in-class scalability.

Licensing
Software FREE (GPL). Commercial support: ~USD 2–15K/year depending on node count. Implementation services quoted separately. Lowest 3-yr TCO of all vendors evaluated.
Server OS
Linux (RHEL, Ubuntu) — primary. Windows NOT supported as server. TimescaleDB recommended for large-scale deployments.
Flow Support
⚠️ Not native. Requires external tool: ntopng (recommended), pmacct, or Elastic-based stack. Adds deployment complexity.
ServiceNow
Via media type webhook. Community-maintained templates available. Not a native certified integration.
Strengths
  • Zero software licensing cost — dramatically lower TCO
  • Proven at 100K+ node scale with TimescaleDB
  • Highly customizable — monitors anything via custom items
  • Native Linux deployment — no Windows Server required
  • Active development (v7.x); large global community
  • Native HA since v6.0 with no additional license cost
Weaknesses
  • No native NetFlow/sFlow — requires ntopng integration
  • Higher initial setup effort; not plug-and-play
  • UI is functional but less polished than commercial tools
  • MENA commercial support coverage should be verified
  • Requires Linux server administration expertise
Centreon IT Monitoring
Centreon SAS · centreon.com
✅ Tier 2 — Fallback Only

French monitoring platform with Nagios roots. Enterprise edition targets large enterprise and service providers. Growing European and Middle East presence. Flow analysis requires a paid MAP add-on — not native in base product.

CodeOx Assessment

Centreon is capable but flow analysis is not native and topology maps require a paid add-on. Limited GCC regional presence. Recommend as fallback Tier 2 only.

Cisco Catalyst Center (formerly DNA Center)
Cisco · cisco.com/site/us/en/products/networking/catalyst-center
⚠️ Conditional Only

Cisco's campus network management and assurance platform. Provides deep visibility for Cisco infrastructure but leaves significant monitoring gaps for non-Cisco devices (Juniper, Fortinet, Palo Alto). Requires dedicated hardware/virtual Cisco appliance.

CodeOx Assessment

Only recommend if the campus network is >80% Cisco. For a genuinely multi-vendor environment, Catalyst Center does not replace SolarWinds comprehensively. Could be deployed alongside another NMS for Cisco-specific automation, but this increases complexity and cost. Not recommended as the sole SolarWinds replacement.

Section 7
CodeOx Recommendations
#1
PRTG Network Monitor (XL or Enterprise License) — Primary Recommendation
Best user experience and fastest time-to-value of all evaluated platforms. Lowest migration friction from SolarWinds — most intuitive UI with 200+ out-of-box sensor types covering all Cisco device classes. The XL (unlimited sensor) or Enterprise license is the correct SKU for this scale — avoids per-sensor cost management at 80K+ interfaces. Strong enterprise track record with 500,000+ global installations. Windows Server deployment is a known constraint but manageable on the pre-provisioned VM.
#2
WhatsUp Gold Total Plus — Alternative
30-year track record as a direct SolarWinds NPM competitor. Flow analysis, topology, and dependency-aware alerting all included in the base product. Clean modern UI with strong pre-built dashboards. The main constraints are Windows Server only and limited GCC/KSA regional support presence, but both are manageable. Recommend as the fallback if PRTG does not meet commercial requirements.
#3
Zabbix + ntopng — Budget-Constrained Path
If budget is the primary constraint and the team has Linux operations capability, this stack eliminates all software licensing costs. Zabbix handles SNMP polling, alerting, dashboards, and topology; ntopng provides the flow analysis layer. Combined 3-year TCO is ~USD 20K vs. ~USD 55–60K for commercial alternatives. Requires more implementation effort and an ongoing Linux-skilled operations capability. Only recommended if budget pressure is confirmed as a hard constraint.
Recommended POC Shortlist

CodeOx recommends a maximum 30-day parallel POC with the top 2 vendors before contract award. Suggested shortlist: (1) PRTG Network Monitor → (2) WhatsUp Gold. If both fail commercial requirements, add Zabbix as a budget-constrained third. Define POC success criteria from BRD Section 14 acceptance criteria before initiating.
