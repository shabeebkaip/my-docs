Why the Custom plan

Odoo's cheaper Standard plan ($13.50 per user per month in Year 1, $16.90 after that) runs only on Odoo's shared online cloud. It cannot be hosted on Odoo.sh or on your own server, and it does not include Odoo Studio, the external API or multi-company. Both server options in this document need the Custom plan. It covers every Odoo app and leaves room for custom features and integrations later.

How the Odoo.sh price is made up (Odoo · Saudi Arabia)

1 worker $57.60/mo + 80 GB storage $16.00/mo ($0.20 per GB) + 1 staging (test) copy $14.40/mo = $88.00 a month ($1,056 a year). One worker is enough for a 10-user team. If usage grows, each extra worker adds $57.60 a month.

Our recommendation

Option A: Odoo.sh. This is the safest choice. Backups are kept on 3 servers in different locations, Odoo supports the platform directly, and Odoo monitors it around the clock. Upgrades and test copies are handled on the platform. For business-critical data, this protection is worth the extra cost.

Option B: LightNode. Choose this if keeping costs down matters most. It is a low-latency Middle East server that Code-ox sets up and maintains for you, and it saves about SAR 2,600 a year compared with Odoo.sh.
